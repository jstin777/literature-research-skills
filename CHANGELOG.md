# Changelog

## 0.1.0 — 2026-11-06

- Initial public source, skills-only plugin, three individual skills and optional local connector packages.
- Preserved subject discovery, direct LibKey access, fresh writer handoff and explicit-only staged multi-agent review.
- Removed private vault paths, folder taxonomy and local import-script assumptions from reusable Zotero guidance.
- Added pinned Python dependencies, explicit installation/configuration tools, private-state exclusions, release allowlist and reproducible ZIP/checksum generation.
- Added distribution and Semantic Scholar regressions; included existing catalogue, OpenAlex and full-text recovery tests. See the compatibility report for live service limitations.
